Private, or simple.
Never both.

So we built both.

Why we built it

The private tools we found were made for developers. Everything simple sent your work to a cloud. Garden Desk is one download that asks nothing of you.

  • No runtime to install
  • No model to pick
  • Nothing to wire together

What stays private

Garden Desk makes no network calls of its own.

  • No telemetry, no error reports, no update checks
  • The agent works in a virtual machine with no network connection
  • The folder you select is mounted read-only
  • The model cannot reach the internet or change your originals

About the name: the cloud is a noisy city with no privacy. Garden Desk is your own desk in a private backyard, where nobody tracks you.
